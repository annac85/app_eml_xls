# 📄 Парсер .eml файлов в Excel
 
![Python](https://img.shields.io/badge/Python-3.7%2B-blue)
![GUI](https://img.shields.io/badge/GUI-Tkinter-orange)
![License](https://img.shields.io/badge/License-Restricted-red)
 
Программа для автоматического извлечения данных из писем `.eml` (заявки с вебинаров, курсов, форм) и сохранения их в Excel.
 
> Кейс: за 4 дня до вебинара пришло 600 заявок вместо ожидаемых 60. Вручную это не собрать в срок — за 3 дня написала парсер + генератор PDF-сертификатов. Вебинар состоялся вовремя, инструмент используется в организации до сих пор.
 
---
 
## Что делает
 
- Сканирует папку и подпапки на `.eml` файлы
- Извлекает ФИО, email, организацию, должность, программу и другие поля по шаблону
- Сохраняет всё в структурированный Excel
- Работает через простой GUI — без командной строки
## Стек
 
Python, Tkinter → Flask (веб-версия), IMAP, pandas, openpyxl
 
## Результат
 
| 600 | 2 недели → 2–3 часа | 3 дня | 2 → 1 |
|---|---|---|---|
| заявок в пиковом потоке | цикл всего вебинара | от постановки задачи до рабочего MVP | сотрудников на обработке |
 
Полный разбор кейса — с матрицей требований, эволюцией версий и архитектурой шаблона сертификата — на [cherkasovaanna.ru](https://cherkasovaanna.ru).

## Установка и запуск
 
```bash
pip install pandas openpyxl
python main.py
```
 
> `tkinter` идёт в стандартной поставке Python и через pip не ставится.
